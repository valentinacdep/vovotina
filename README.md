## Plataforma digital desenvolvida para auxiliar idosos em tarefas do dia a dia, oferecendo suporte tecnológico simples e acessível.
Aplicação desenvolvida com foco em acessibilidade digital para idosos, oferecendo ferramentas simples para auxiliar no cotidiano. O projeto utiliza Node.js no backend e React Native no frontend.
